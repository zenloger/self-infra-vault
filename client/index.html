Вход пока не настроен. Владелец сервера должен указать параметры приложения Яндекс OAuth. Мастер-пароль к Яндексу не относится.

Сайт должен быть доверенным: его JavaScript получает доступ к открытой базе. Без аналитики, внешних скриптов и хранения расшифрованных данных на диске браузера.

Яндекс Диск / secret

Хранилища

Каждая синхронизация создаёт отдельную версию файла. Предыдущие версии сохраняются.

    В папке пока нет файлов .kdbx. Создай новое хранилище или положи существующее в /secret на Диске.

    Открыть локально

    Пароль и ключевой файл используются только здесь. При создании пароль должен быть не короче 12 символов. Ключевой файл придётся хранить отдельно: без него базу не открыть.

    Открыто в этом браузере

    Исходный файл изменился на Диске.

    Твои изменения остаются в памяти. Сначала скачай зашифрованную копию. Можно объединить исходный файл с открытой базой; результат проверь и сохрани отдельной версией.
